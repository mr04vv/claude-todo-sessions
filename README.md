# claude-todo-sessions

todo や GitHub issue を Claude Code のセッションに紐づけるローカルツールです。紐づけ先は Claude Desktop の Code タブのセッションでも CLI のセッションでも構いません。

- セッション内から MCP ツールで todo を操作できます（一覧・作成・更新・紐づけ）
- 起動時のプロンプトに `[todo:<id>]` を入れておくと、そのセッションが自動で todo に紐づきます
- hook がセッションの状態（running / needs_input / idle / ended）を記録します

機能の紹介（画像と動画つき）は [docs/features.md](docs/features.md) にあります。

設計は [設計書](https://claude.ai/code/artifact/8574c0b4-3336-416f-b00d-bd6769bf6b8c) にまとめています。

## 構成

| パス | 役割 |
| --- | --- |
| `crates/core` | SQLite に todo とセッションを保存するロジック |
| `crates/cts` | `cts mcp`（stdio の MCP サーバー）と `cts hook <event>`（hook の受け口）を持つ CLI |
| `plugin/` | Claude Code プラグイン（hooks・MCP 設定・skill） |
| `.claude-plugin/marketplace.json` | 手元のリポジトリからプラグインを入れるためのマーケットプレイス定義 |

## ビルド

```sh
cargo build --release
cargo test
```

`.cargo/config.toml` で、リンカと C コンパイラに macOS 標準の `/usr/bin/cc` を指定しています。nix の gcc が `cc` になっている環境では、`-liconv` が見つからずビルドに失敗するためです。

## インストール

```sh
cargo build --release
claude plugin marketplace add /path/to/claude-todo-sessions
claude plugin install todo-sessions@claude-todo-sessions
```

インストール時には `target/release/cts` がプラグインのキャッシュにコピーされます。ビルドし直した場合は、`plugin/.claude-plugin/plugin.json` の version を上げてからプラグインを更新してください。

開発中は、インストールせずに次のように直接読み込むこともできます。

```sh
claude --plugin-dir ./plugin
```

## アプリ

`app/` は Tauri + React のデスクトップアプリです。

```sh
cd app
pnpm install
pnpm tauri dev      # 開発用に起動
pnpm tauri build    # target/release/bundle/macos/Shosai.app を作成
```

ビルドした `.app` は `/Applications` に置いて使います（ビルドし直したら入れ替えます）。

```sh
pkill -x todo-sessions-app; sleep 1; rm -rf "/Applications/Todo Sessions.app" "/Applications/Shosai.app" && cp -R target/release/bundle/macos/Shosai.app /Applications/ && open /Applications/Shosai.app
```

### 画面

ウインドウの左端のレールに「場」が並びます。上の組が仕事をする場（管理・作業・学習・ブラウザ）、線の下の組が届くもの（Slack・成果物）です。⌘1〜⌘6 で移り、各場は前に見ていたところから始まります。作業のアイコンには「あなた待ち」の数（オレンジ）、Slack のアイコンには未読の数（青）が付きます。レールの下には Claude の使用量、⌘K、設定があります。

⌘K で操作と todo・セッションの検索、⌘N で todo の追加ができます。⌘K の一番上の「セッション一覧」（⌘⇧K で直接）を選ぶと、動いているセッションが並び、選ぶと作業で開きます。キーは ⌘K の「ショートカットを見る・変える」（Todo では ? でも）で一覧でき、そこで変えられます（ブラウザのページの中でも同じキーが効きます）。⌘R は今の画面のデータを取り直します（ページにキーボードがあるときはページの再読み込み）。

入力先（キーボードがある場所）は、その帯が青く色付き、上に太い線が出ることで分かります（ほかの帯は薄くなります）。⌃l で右（ページ）へ、⌃h で左（一覧、さらにサイドバー、いちばん左はレール）へ移ります。

#### 管理（⌘1）

左のサイドバーで Todo・PR と、自分で作った DB（todo の束）を切り替えます。

- Todo：カンバン（Todo / Doing / Review / Pending / Done の5列）とリストがあり、「Doing」で今日やるものだけを並べます。Pending は外部の返事待ちなどで止めている todo です
  - 「リポジトリ」でまとめると最初のリポジトリごと、「親 Todo」でまとめると親 todo ごとのレーンに分かれます。レーンは左の ▾ で折りたたみます
  - カードを列のあいだで動かすと status が変わります。各列の「＋ 新規」でその場で todo を追加できます（親のレーンではサブタスクになります）
  - キーボードだけで操作できます。j k で移動（カンバンは h l で左右の列、リストは h l でレーンの開閉）、Enter で todo のシート（e でタイトル、m でメモ、a でサブタスク）、s でステータス、⇧h ⇧l でカードを左右の列へ、⌘⇧[ ⌘⇧] で前・次のレーン、o で作業で開く（セッションがなければ起動シート）、⌘Enter で起動シート、p で PR / issue、u で親の todo、c でその場所に todo を追加、/ で絞り込み欄へ
  - 「絞り込み」と「フィルター」はカンバンとリストで別々に持ち、アプリを閉じても残ります。「保存…」で名前を付けると、ビューとして呼び出せます
- todo のシート：タイトル・ステータス・場所・親・issue / PR・フォルダ・メモ・リンクをその場で編集できます
  - 「セッションを始める」（⌘Enter）で起動シートを開き、最初のプロンプト・スキル・起動先（Cloud か herdr）・Claude か Codex・モデルと effort を選んで始めます。リポジトリが2つ以上の todo は計画用で、Local の指揮役が計画を立ててサブタスクを作ります
  - Codex は herdr の中だけで動き、最初のプロンプトの `[todo:N]` で todo に紐づきます。閉じたものは `codex resume` で再開します
- PR：自分へのレビュー依頼（`gh search prs --review-requested @me`）と自分の PR（`--author @me`）を並べます。f ですべて・レビュー依頼・自分の PR を切り替えます
  - レビュー依頼で Enter を押すと、todo を作らずにレビューのセッションを始めます。エージェント（Claude / Codex）、提出（提出前に確認する / 自動で提出する）、動く場所（Cloud / herdr）は上で選びます
  - 自分の PR で Enter を押すと、CI の失敗や修正の依頼を元のセッションに直させます。o で作業で開きます
  - 「GitHub で見る（ここで）」（⌘Enter）で、右の詳細がその PR の GitHub のページに替わります。PR ごとに自分のページを持ち、j k で別の PR に移るとそのページが出ます。⌃l でページに、⌃h で一覧に戻り、Esc で詳細に戻ります。「ブラウザで開く」でブラウザのウインドウに開きます
  - アーカイブされたリポジトリの PR は出ません

#### 作業（⌘2）

左に作業の一覧、右にセッションを表示します。親 todo（指揮役がいるもの）を選ぶと、指揮役のセッションが真ん中に、サブタスクのセッションが右に並びます。

- 一覧の上は「あなた待ち」（返事待ち・CI の失敗・修正依頼・指揮役から回されたもの・まだ始めていないレビュー依頼）、その下が作業中のセッションのカードです。並べ方は s で切り替え（手で並べた順・動きがあった順・始めた順）、⇧j ⇧k かドラッグで並べ替えます
- カードには、状態（作業中・返事待ち・ひと区切り・終了）、未読の点、番号とタイトル、経過時間に続いて、次のものが出ます
  - 返事待ちならその質問。それ以外は、いま何をしていてどこまで進んだかの1文の要約（最近のやり取りを Claude の haiku が読んで作ります。状態が変わったときだけ作り直し、アプリを閉じても残ります）
  - 指揮役から回されたことがあれば、その内容
  - リポジトリ・場所（Local の herdr か Codex、Desktop、Cloud）・モデル・コンテキストのサイズ（82k など）
  - PR の段階、CI の失敗、成果物の数
- 指揮役のカードには、サブタスクの要約（状態ごとの色の帯、何件 Done か、返事待ちの数）が付き、その下にサブタスクの小さなカードが入ります。「▸ サブタスク」か l で開き、h で畳みます（サブタスクが返事待ちのときは自分で開きます）。Done のサブタスクは薄い1行、まだ始めていないものは点線の1行です
- 選んでいるカード（右に出しているもの）は青く色付き、左に太い線が出ます。j k のカーソルは外側の輪で分かります
- 右のサブタスクのタブは × か ⌘W で右から外せます（セッションは動いたまま）。外したものは一覧から開くと戻ります
- 右側は「右を隠す」か ⌘⇧E で隠したり出したりできます（隠すと入力先は左に移ります）
- ヘッダーの「成果物」か ⌘⇧O で、右側がその todo（サブタスクの分も）の成果物の一覧に替わります。j k で選び、Enter で横に、⌘Enter でブラウザに開きます（Esc で戻る）。表示しているセッションが成果物を作ると、右側に自動で開きます（入力先は動きません）
- 横に開いたページは、開いた todo かセッションのものとして残り、別の作業に切り替えると隠れます（アプリを再起動すると消えます）
- 「ちょっと Claude」で、todo に紐づけずに herdr でホームフォルダの claude を開きます

ターミナル：設定の「ターミナル」で、Local のセッションを動かす場所を Ghostty（herdr。既定）かアプリ内にするか選べます。アプリ内にすると、作業のペインにターミナルが出ます。herdr が動いていれば、セッションは herdr の新しいワークスペースで動き、ペインはその herdr を表示します。

- 見た目とキーは Ghostty の設定に合わせます（フォント・サイズ・余白・テーマ・カーソル、`ghostty +list-keybinds` のキー）
- ターミナルのリンクは、⌘ クリックで作業の右側（セッションの横）に、⌘⇧ クリックでブラウザのウインドウに開きます。⌘⇧L で、ターミナルに出ているリンクが ⌘K の箱に並び、Enter で横に、⌘Enter でブラウザに開きます

#### 学習（⌘3）

読みもの（記事・X の投稿・本）の一覧です。ブラウザでページを ⌘⇧D（O'Reilly の本のページなら本として目次ごと）か、リンクを ⌥ + クリックすると入ります。j k で選び、Enter で読みます。x で選んだものはまとめて読め、URL を NotebookLM 用にコピーできます。読んでいるときは左にページ、右に ChatGPT・Claude・NotebookLM が並び、⌃h ⌃l で行き来します。毎朝、前日の読みものから日報を作ります。

#### ブラウザ（⌘4）

ブラウザは「Shosai ブラウザ」という別のウインドウです。⌘4 かレールの「ブラウザ」で前に出ます。ブラウザで開くもの（PR やリンクの ⌘⇧ クリック、成果物の ⌘Enter、通知の PR など）は、すべてこのウインドウのタブとして開きます。閉じても隠れるだけで、タブは残ります（アプリを再起動しても戻ります）。「← Shosai に戻る」か ⌘1〜⌘6 でメインのウインドウに戻ります。

- 左がタブの一覧、上に固定のページ（OneLogin・NotebookLM・ChatGPT・Claude と、自分で固定したもの）が並びます。タブを固定の並びへドラッグすると固定になり、右クリックで外せます
- ⌘T で新しいタブ、⌘W で閉じる、j k で一覧を選んで Enter で開く、d でカーソルのタブを閉じる、⌘⇧[ ⌘⇧] でタブを切り替え、⌘L でアドレス欄（これまでに開いたページから候補が出ます）、⌘[ ⌘] で戻る・進む
- ⌘⇧G で、表示中のページ（文を選んでいればその文）を右の ChatGPT に解説してもらいます。新しいチャットで、要点・背景・難しい用語の説明を日本語で頼みます。右側は × で閉じ、幅はドラッグで変えられます
- ログインはアプリを再起動しても保たれます。ログインを送信すると、そのサイトのユーザー名とパスワードを Keychain に保存するか聞き（項目名 `shosai-login`、サイトごとに1組）、保存したサイトのログイン画面では自動で入力して送信します。設定の「保存したログイン」で消せます
- claude.ai の Cloud セッションのページでは、⌘⇧A でそのセッションをアーカイブしてタブを閉じます
- ページが新しいウインドウで開くリンクも、このウインドウのタブになります。ctrl を押しながら開くと、いつものブラウザで開きます

#### Slack（⌘5）

自分へのメンションと、追っているスレッドの新しい返信を並べます。f で未読・メンション・スレッド・既読・ブックマークを切り替え、Enter でスレッドを開きます。スレッドから返信、リアクション、Todo にする、Slack で開くができます。

#### 成果物（⌘6）

セッションが作った claude.ai の Artifact・Doc と、登録したファイルの一覧です。Enter で開き、一覧から消すこともできます。

#### 設定

レールの下の歯車から開きます。Cloud のセッションを開く場所（Web か Claude Desktop）、ターミナル、herdr のセッション、学習の API キー、OneLogin のポータル、Slack、保存したログイン、サイトのマイク・カメラの許可を設定します。

### 自動で行うこと

- クラウドセッションを30秒ごとに同期します
- GitHub は1分ごと（ウインドウを前に出したときと「今すぐ同期」でも）に同期します
  - `claude/todo-<id>-` ブランチの PR、またはセッションの作業ブランチでセッション開始後に作られた PR を todo に紐づけます
  - PR にレビュー依頼が入るか Approve されると Review、修正依頼で Doing、マージで Done にします。マージ時は、紐づいた issue が開いていれば close します
  - issue が close されたら Done にします
- サブタスクが全部 Done になると、親の todo も Done にします
- Done になった todo の Cloud セッションを、ターンが終わっていればアーカイブします
- 紐づいたセッションが入力待ちになったときや、作業が終わったときに通知します。通知をクリックするとそのセッションが開き、アプリの通知一覧からも消えます
- 自分へのレビュー依頼が新しく来たら通知します。通知をクリックすると PR が開きます
- 作業のカードの要約を、セッションの状態が変わったときに作ります（`claude -p` で haiku を1回呼び、ツール・MCP・フックなし、会話は保存しません）
- ウインドウを閉じてもメニューバーに常駐します。メニューバーのアイコンから、入力待ち・待機中のセッションを開いたり、アプリを終了したりできます

## 使い方

- セッションの中で「この作業を todo #3 に紐づけて」「todo を一覧して」のように頼むと、Claude が MCP ツールを使って操作します
- todo に紐づけた状態で新しいセッションを始めたいときは、最初のプロンプトに `[todo:<id>]` を含めます
  - Desktop から始める場合は `open "claude://code/new?folder=<cwd>&q=%5Btodo%3A<id>%5D"` を使います。プロンプトが入力欄に入った状態で開きます
- `cts cloud sync` を実行すると、クラウドのセッションの状態を取り込み、最初のプロンプトに `[todo:<id>]` があるセッションを紐づけます
  - 非公開 API（`/v1/code/sessions`）を使うため、仕様が予告なく変わる可能性があります
  - Keychain の "Claude Code-credentials" を読みます。トークンの期限が切れていれば更新して書き戻します
- 既存のセッションを Desktop で開くには `open "claude://resume?session=<session_id>"` を使います

## データ

- DB：`~/Library/Application Support/claude-todo-sessions/db.sqlite`（環境変数 `CTS_DB` で変更できます）
- エラーログ：DB と同じディレクトリの `cts.log`
